# Выгрузка из Figma без REST API

Готовый локальный плагин. Node.js, npm, API-токен и платный MCP для его кода не нужны.

1. Установи Figma Desktop для Windows: https://www.figma.com/downloads/
2. Войди в свой аккаунт и открой доступный тебе исходный макет.
3. В меню Figma выбери Plugins → Development → Import plugin from manifest…
4. Выбери `manifest.json` из этой папки. Не перемещай остальные файлы отдельно от него.
5. В списке Layers слева выдели целый фрейм нужной секции (например, футер).
6. Plugins → Development → BS — Выгрузка макета.
7. Нажми «Подготовить JSON + PNG». Дождись ссылок и сохрани оба файла.
8. Передай JSON и PNG в задачу с вёрсткой. Для отдельного логотипа или иконки включи SVG.

Если Figma требует создать ID плагина, используй Plugins → Development → New plugin → Figma design → Custom UI. Сохрани новый плагин в отдельную папку, затем замени в ней только code.js и ui.html файлами отсюда. Сохрани manifest.json, созданный Figma, включая его id. Убедись, что он ссылается на code.js и ui.html.

Нужны права на запуск плагинов и экспорт в выбранном файле. При запрете попроси владельца разрешить экспорт или выдать доступную копию. Этот плагин не меняет права доступа.

JSON_REST_V1 — название формата сериализации в Plugin API, а не сетевой REST-запрос. JSON содержит дерево выбранного узла с параметрами; изображения-заливки могут быть представлены ссылочными идентификаторами, поэтому JSON не заменяет экспорт картинок. PNG экспортируется в масштабе 1×, SVG — по желанию. На больших фреймах возможны ограничения памяти и экспорта Figma; тогда выгружай секциями.

Плагин не изменяет документ и не имеет сетевого доступа. Скачивание запускается отдельным нажатием каждой ссылки. Файлы сохраняются средствами Figma/браузерного движка, не автоматически в репозиторий.

Проверены синтаксис, обработка сообщений и формирование скачиваемых файлов вне Figma. Реальный запуск внутри Figma требует установленного приложения и доступного макета; пока не проверен.

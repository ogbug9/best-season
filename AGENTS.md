# Заметки по репозиторию

Постоянный контекст проекта: стек, структура, команды, ловушки. Читается
в начале сессии вместо того, чтобы перечитывать репозиторий.
Состояние работы — что сделано и что дальше — лежит в `HANDOFF.md`.

## Общение и экономия токенов

Всегда экономить токены в этом проекте: отвечать кратко и по делу,
без повторов и лишних пояснений. Подробности — по запросу пользователя.
Проверки, необходимые для корректности работы, не пропускать.

## Стек

Python 3.11, Django 5, Wagtail, PostgreSQL. Фронтенд без сборки:
HTML-шаблоны Django, CSS вручную, Alpine.js, Swiper.js — React и Vue не
используются. Бронирование — внешний виджет Контур.Отель. Хостинг Amvera.

## Выкладка

У репозитория два remote, и они делают разное:

| remote | адрес | зачем |
|---|---|---|
| `origin` | github.com/ogbug9/best-season | история, ничего не деплоит |
| `amvera` | git.msk0.amvera.ru/sfnvsd24/best-season | сборка и выкладка |

Пуш только в `origin` сайт не обновляет — Amvera тянет из своего remote и про
GitHub не знает. Ветка у Amvera называется `master`, у нас `main`, поэтому
двоеточие в последней команде обязательно.

```
git add -A
git commit -m "Сообщение"
git push origin main
git push amvera main:master
```

Наполнение (`python manage.py seed_content`) прогоняется при старте контейнера
само, отдельно запускать после деплоя не нужно.

## Сверка с макетом

`design/spec.json` — реестр измеренных значений, `design/check_spec.py` сравнивает
с ним живую страницу. Правила работы с реестром описаны в самом файле
(`_meta`), там же две ловушки, на которые уже наступали:

- **`_meta.ловушка_line_height`** — «Line height 100%» в панели Figma означает
  Auto, а не 1.0. Считать 1,22 от кегля.
- **`_meta.сверка_браузера`** — `check_spec.py` запускает Chromium без
  `executablePath`, и метрики шрифта могут отличаться от закреплённой сборки.
  Значения, зависящие от переноса строк, закреплять в CSS, а не полагаться на
  содержимое.

Догадки в реестре запрещены и это проверяется тестом
`core.tests_spec.RegistryIntegrityTests.test_registry_has_no_guesses_left`.
Всё неизмеренное идёт в раздел `открытые_вопросы`, а в `components` кладутся
только настоящие CSS-свойства — координаты и прочее, чего нет в
`getComputedStyle`, оформляются отдельными полями.

## Шрифты

Свои файлы в `config/static/fonts`, Google Fonts CDN не используется
(п. 10.11 ТЗ). Подключение и лицензии — в `config/static/css/fonts.css`.
Начертания: Montserrat 400 и 600 прямые, Montserrat 300 italic (только
слоган), Inter 400 (нижняя строка подвала), Etude Noire 400/500/700.
Другого веса или наклона в файлах нет — браузер подделает его из
имеющегося и строка станет шире. На этом уже обожглись: слоган срывался
на третью строку.

## Метрики шрифта против Figma

Chromium рисует текст примерно на 1.5% шире, чем показывает панель Figma.
Это не ошибка вёрстки: 559 против 551 в меню, 435 против 428 в правой
группе шапки, 765 против 755 в слогане. Правило: подгонять под
фигмовское число, ломая типографику, нельзя; там, где от ширины зависит
перенос строки, перенос закрепляется в тексте.

## Зазоры в панели Figma

Значение `gap` в панели у блока с `space-between` — номинальное, а не
фактическое. Считать по координатам: жёстко заданный `gap: 60` в шапке
раздул содержимое до 1323 при ширине пилюли 1260, и кнопка вылезла
за скругление.

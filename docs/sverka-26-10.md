# Сверка «Территории» и «Чем заняться» с макетами (26.10.2026)

Метод: эталон — рамки элементов прямо из SVG-выгрузок Figma (`Desktop\Макет PNG SVG`): каждый текстовый слой там один `<path>`, его рамка — точные границы «чернил». Сайт снимается в 2x (Playwright, Edge), в рамке DOM-элемента ищутся «чернила» нужного цвета и сравниваются с макетом по x, y, ширине и высоте. Допуск — 1,5 px. Для вставленных в макет скриншотов (бинго, кубик, чек-лист, плитки) размеры сняты с растра макета в 2x. Скрипты: scratchpad сессии (`svg_geom.py`, `measure.cjs`, `compare.py`, `spec_*.py`).

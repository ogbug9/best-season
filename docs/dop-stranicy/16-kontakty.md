# 16 — Контакты `/o-nas/kontakty/`

Исполнитель: Codex · Волна 0 · Зависит от 01
Цель: связаться одним нажатием. Сейчас гость видит указание для администратора и не видит ни телефона, ни мессенджеров.

## Сейчас
- `core/templates/core/contacts_page.html`, `ContactsPage` (intro, body, map_*). body = «Контакты и реквизиты берутся из настроек сайта — заполните их…».

| 1 | Плитки связи | Telegram · WhatsApp · Телефон · VK из `SiteSettings`; иконки подвала; hover заливка #E5D0C0; на телефоне 2×2, высота ≥ 64 px; незаполненная плитка не выводится | Д3, Д8 |

## Поведение
- Telegram/WhatsApp открываются с текстом «Здравствуйте! Хочу забронировать домик» (`?text=`); `contact_click{channel}`.
- Телефон на десктопе: копирование номера + success-состояние кнопки; на телефоне `tel:`.
- Текст body, совпадающий со служебной фразой о настройках, гостям не выводится (guarded-очистка или фильтр). Без CTA брони — контакты и есть шаг к брони.

## Данные
- Telegram, WhatsApp, VK, адрес — уже в подвале прода. Спрошу у команды основной телефон для `SiteSettings.phone` (в соцсетях их три).

## Готово
- В HTML нет фразы «заполните их в разделе»; тест: пустые настройки → плиток нет, страница 200.

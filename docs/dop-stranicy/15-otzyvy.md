## Модель и настройки
- `ReviewsPage` (или `SiteSettings`): `yandex_rating` (Decimal 2,1), `yandex_ratings_count`, `yandex_reviews_count`, `yandex_tags` (CharField). Пусто → блок 1 не выводится.
- JSON-LD `AggregateRating` из тех же полей.

## Данные
- 5,0 · 67 оценок · 55 отзывов — https://yandex.ru/maps/org/luchshiy_sezon/3306085141/reviews/ (на 07.10.2026).
- Домик у старых отзывов — по тексту («Были в домике №1» → №1); непонятные оставить без домика. Спрошу у команды только про неясные.
- Новые отзывы из VK «Обсуждения» и Яндекса — вручную, с именем и ссылкой; без автоматического копирования.

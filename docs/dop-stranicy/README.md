## Общие правила для любого исполнителя

1. Сначала прочитать `AGENTS.md`, `CLAUDE.md`, конец `HANDOFF.md` и `01-komponenty.md`. Правила AGENTS.md важнее этого файла.
2. Цифры и факты с сайта (БД, FAQ, карточки) актуальны и важнее соцсетей. Новые факты — только с источником из ТЗ; чего нет — оставить поле пустым, сайт пустое поле не показывает.
3. Никаких новых стилей «с нуля»: токены `config/static/css/main.css` (`--c-cream`, `--c-deep`, `--c-terra`, `--c-blush`, `--c-sand`), шрифты Etude Noire / Montserrat, существующие карточки, кнопки (`buttons.css`), аккордеон, лайтбокс.
4. Движение — только коды Д1–Д10 из `01-komponenty.md`; всё уважает `prefers-reduced-motion`.
5. Видео не встраивать. Где в ТЗ «место под видео» — компонент `video_slot` (заглушка).
6. Фото — только из уже загруженных (wagtailimages). Новые картинки не скачивать.
7. Мобильная вёрстка с 699 px, как на остальном сайте; цели нажатия ≥ 44 px.
8. Миграции данных — только guarded (менять значение, если оно равно известному старому), как `core/migrations/0024_*`.
9. Проверки: точечные тесты Django для новой логики, `manage.py check`, рендер страницы через тестовый клиент. Браузерная сверка — только если её попросили.
10. Коммиты/push/выкладка — только по запросу владельца. После работы — короткая запись в `HANDOFF.md`.

## Аналитика (единая для всех страниц)

- Кнопки брони: существующий `data-booking-open` + `data-entry-point` (номер по ТЗ: 7 — контентные страницы, 8 — «Как добраться»). Новое: `data-entry-page="<slug-страницы>"`, `kontur.js` добавляет его в событие `booking_widget_open` параметром `page`.
- Контакты: `contact_click{channel}`; формы: `form_submitted{form_type}`; маршрут: `directions_click`.

## Определение «готово» для каждой страницы

- Нет служебных слов («Текст ожидается…», «уточняется», «Описание») в HTML.
- 1440 и 390: нет горизонтального скролла, CTA брони в конце страницы (кроме «Партнёрам» и служебных).
- Пустые поля CMS не оставляют пустых блоков.
- Если раздел неполный — включена плашка «Раздел дополняется» (поле `in_progress`), страница при этом полезна.

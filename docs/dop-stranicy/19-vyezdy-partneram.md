## Партнёрам `/o-nas/partneram/`
- Три плитки (Д1): «Съёмки и блогеры» (кейс команды Алины Загитовой — карточка «Фотосессии»; выпуск блогеров на Rutube из Telegram 18.02.2025), «Ведущие мастер-классов» (живопись, флористика, йога), «Местные партнёры» (экскурсии, корт).
- В плитке «что предлагаем» и «что ждём»; нажатие → форма `FormType.PARTNER` с выбранным направлением.
- Место под медиакит PDF: заглушка «Презентацию пришлём по запросу». Без CTA брони.

## Данные
- Спрошу у команды: действует ли «Только свои» круглый год, можно ли упоминать съёмки с Загитовой отдельно, условия для партнёров. До ответа обе страницы с плашкой `in_progress`.

## Готово

### Berold — НЕ ИСПОЛЬЗУЕТСЯ
Шрифт есть в макетах Figma, но на сайт не подключён.
Лицензия JS Studio (Joko Setiono): бесплатно только для личных проектов,
коммерческое использование запрещено, в условиях указан штраф от 4000 USD.
Кириллическая версия, распространяемая в рунете, — сторонняя кириллизация,
на неё лицензия оригинала не распространяется.
Решение о замене или покупке лицензии — за Заказчиком (п. 4.6, п. 9.1 ТЗ).

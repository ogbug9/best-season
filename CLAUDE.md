# Инструкции для Claude

Единые правила проекта — в AGENTS.md. Следовать им; не дублировать их здесь.
По умолчанию — только код текущей задачи и минимальные необходимые проверки.
MCP, картинки, браузер, отчёты и остальные дополнительные действия — только по прямому запросу.
После каждой рабочей сессии кратко обновлять `HANDOFF.md` согласно AGENTS.md. `.ai/task.md` и `.ai/review.md` остаются историческими записями и автоматически не обновляются.

При работе с фоном главной сверяться с текущими шаблонами и CSS, присланным эталоном и актуальной записью в `HANDOFF.md`. Фон привязывается к секциям страницы и проверяется после рендера; не менять якорь на процент общей высоты документа без согласованных координат.
